# Upload this app to a private GitHub repository

1. Extract the ZIP on your Windows computer.
2. Install GitHub Desktop from https://desktop.github.com/ and sign in.
3. In GitHub Desktop, choose File > New repository. Name it elevated-drawing-review and create it in a folder of your choice.
4. Choose Repository > Show in Explorer. Copy all files and folders INSIDE the extracted elevated-drawing-review folder into this new repository folder. The repository root should contain package.json, app, public, scripts, tests, and the other included files.
5. Return to GitHub Desktop. If there are changes, enter Add drawing extractor source in Summary and click Commit to main.
6. Click Publish repository. Keep Keep this code private checked, then click Publish Repository.

This ZIP contains the source and local PDF/OCR assets from deployed commit 2d0d6d3f7ff2a21aca1a132cd9401c10ee7bb895. It excludes Git history, installed node_modules, build outputs, access credentials, and real project PDFs. The fictional example.pdf is included.

This is a React/Vinext app. Uploading the code to GitHub stores a copy; it does not automatically update the private deployed website or configure a Streamlit deployment. The existing private website remains at https://elevated-drawing-review-mk.gloriousflora5.chatgpt.site.
